# Code Engine

High-performance Code, Vector, Graph, and Search Algorithm Engine containing pure algorithmic implementations, capability registry, and composition services.

## Structure
- `src/code_engine/algos`: Modular algorithm catalogs (search, diff, buffer, vector, graph, etc.)
- `src/code_engine/domain`: Algorithm contracts, schemas, and port interfaces
- `src/code_engine/registry`: Capability catalog and algorithm registry
- `src/code_engine/service`: Algorithm orchestration and composition services
